## When this applies

A supplier sends a monthly statement listing invoices, credits and a running balance. It
is usually not a demand, and no single invoice is being chased.

## Steps

1. Compare the statement lines against our payables ledger for the same period.
2. Mark each line as agreed, paid, or in dispute.
3. List the lines in dispute with the reason.
4. If the statement is a reconciliation only, file it and record any credit notes.
5. If a line is genuinely overdue, queue the payment for the owner.
6. Send the marked statement back to the supplier when we disagree with something.

## If you cannot settle it

If the statement balance exceeds our ledger by more than one invoice, escalate. The
difference usually means an invoice was posted to the wrong supplier.
