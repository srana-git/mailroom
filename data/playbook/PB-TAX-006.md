## When this applies

The agency says the GST or QST remitted does not match the return filed, or the return
filed does not match the input tax credits claimed. The letter usually names a period.

## Steps

1. Pull the return for the period named in the letter.
2. Compare our collected and paid tax against the amounts in the letter.
3. Decide which side is wrong. Do not assume the agency is right.
4. If we under-reported, queue a correcting return for the owner.
5. If the agency is wrong, queue a written explanation with the working papers attached.
6. Record the difference and its cause in the ledger.

## If you cannot settle it

If the difference is larger than one filing period, escalate. A pattern of differences
is an audit risk, not a clerical error.
