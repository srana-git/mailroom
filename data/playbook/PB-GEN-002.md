## When this applies

An organisation follows up a question, a request or a complaint we raised earlier. The
letter names a file or a ticket number and asks us to confirm whether the matter is
settled.

## Steps

1. Find our original enquiry by the file or ticket number.
2. Decide whether the matter is settled. If it is, say so and close it.
3. If it is not, restate what is still missing, in one paragraph.
4. Queue the reply for the owner. Reply only to the address or the portal the original
   enquiry used.
5. File the reply with the original enquiry.

## If you cannot settle it

If the letter answers an enquiry we did not make, escalate. It usually means someone is
using our name.
