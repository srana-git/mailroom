## When this applies

The city reminds us that an occupancy, signage or construction permit is about to
expire, or asks for an inspection before renewal.

## Steps

1. Identify the permit by its number and the address it covers.
2. Check whether the work or the use it covers is still current. A permit for a closed
   site is not renewed.
3. Book the inspection the letter mentions, if one is required.
4. Queue the renewal for the owner with the fee.
5. Renew, then file the certificate with the site file.

## If you cannot settle it

If the letter says the permit is already expired or that a fine has been issued,
escalate rather than renewing quietly.
